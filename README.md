CS-300: Data Structures and Algorithms

Course Portfolio Reflection

Overview

This repository contains selected projects from CS-300: Data Structures and Algorithms at Southern New Hampshire University. These projects demonstrate my understanding of data structures, algorithm efficiency, software design, and problem-solving using C++.

Project One: Data Structures Analysis

In Project One, I analyzed the run-time and memory requirements of three data structures: vectors, hash tables, and binary search trees. The objective was to determine which data structure would be most appropriate for a course-planning application by comparing their performance, efficiency, and ability to organize and retrieve course information.

Project Two: Course Planner Application

In Project Two, I developed a C++ application that reads course information from a file, stores the information in a data structure, and allows users to interact with the course catalog. The application provides a menu for loading course data, displaying courses in alphanumeric order, and searching for individual courses and their prerequisites.

Reflection

1. What was the problem you were solving in the projects for this course?

The primary problem I was solving involved designing an efficient course-planning system for the Computer Science program. The application needed to read course information from a file, organize the data, display courses in alphanumeric order, and provide information about individual courses and their prerequisites.

In Project One, I evaluated different data structures to determine which would provide the most effective solution. In Project Two, I applied those concepts to develop a functional C++ application. Both projects helped me understand how important it is to select appropriate algorithms and data structures when developing software.

2. How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by first examining the requirements and identifying the operations the application needed to perform. I developed pseudocode to organize the program's logic before implementing the solution in C++.

I evaluated vectors, hash tables, and binary search trees by analyzing their run-time complexity and memory requirements. This comparison helped me recognize that each data structure has advantages and limitations depending on how information is stored, searched, and retrieved.

Understanding data structures is essential because the choice of structure directly affects a program's performance, scalability, and efficiency. I learned that designing a successful application involves more than writing functional code; it also requires selecting the most appropriate methods for managing data.

3. How did you overcome any roadblocks you encountered while going through the activities or project?

Throughout the course, I encountered challenges involving C++ syntax, implementing data structures, reading and validating input files, and troubleshooting program behavior.

One important challenge was understanding how different data structures manage information and how their operations affect performance. I addressed these challenges by reviewing course materials, breaking larger problems into smaller tasks, revisiting my pseudocode, and testing individual components of my programs.

I also used Visual Studio Code to identify and correct errors while compiling and running my applications. These experiences reinforced the importance of patience, logical thinking, and systematic debugging. Rather than viewing errors as setbacks, I learned to treat them as opportunities to improve my understanding and strengthen my programming skills.

4. How has your work on this project expanded your approach to designing software and developing programs?

These projects significantly expanded my understanding of software development by demonstrating the importance of planning, efficiency, and algorithm selection.

Before completing this course, I often focused primarily on whether a program produced the expected results. Now, I recognize that effective software design also requires evaluating how efficiently a program performs its operations and how well it can handle larger amounts of data.

Analyzing Big O notation helped me understand the relationship between algorithms, computational complexity, and application performance. I also developed a greater appreciation for designing software with a clear structure before beginning implementation.

This experience has encouraged me to approach future programming challenges with a stronger emphasis on analysis, organization, and long-term efficiency.

5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

My experience in CS-300 has helped me become more intentional about writing code that is organized, understandable, and easier to maintain.

I learned the importance of using descriptive variable names, separating program responsibilities into functions, and maintaining consistent formatting. I also recognize the value of comments and documentation in explaining complex logic and helping other developers understand a program's purpose.

Additionally, implementing data structures reinforced the importance of designing programs that can be modified or expanded without requiring major changes to the entire application.

Moving forward, I plan to apply these principles by developing modular programs, validating input carefully, testing functionality regularly, and considering how future requirements may influence my design decisions.

Conclusion

CS-300 has strengthened my foundation in computer science by connecting theoretical concepts with practical programming experience. Through these projects, I developed a deeper understanding of data structures, algorithm analysis, computational efficiency, and software design.

More importantly, I learned that successful software development requires a balance between functionality, performance, readability, and maintainability. These lessons will continue to guide my growth as a computer science student and future software development professional.
